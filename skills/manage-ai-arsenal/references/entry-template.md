# Catalog entry

Use the destination's existing style. Preserve useful fields already present.

```markdown
## Resource name

- Source: [owner/repository or official title](https://example.com)
- Category: existing category; kind: reference / library / skill / integration.
- Purpose: factual, short description.
- Use and caveats: when useful, compatibility or setup implications.
- Review: reviewed / needs-review / deferred / archived, YYYY-MM-DD;
  evidence: official page and repository revision/blob when available;
  gaps or reason if applicable.
- FirstIQ fit: project-specific rationale, when writing to FirstIQ.
- Adoption: reference-only / proposed / adopted / retired / unknown;
  environment, version/revision, approval and validation evidence if known.
```

For capture, a bare URL plus the owner's optional note is enough. Do not require
this template before a link can enter the inbox. Keep example placeholders out
of real catalog entries.
