# AI Arsenal

A personal resource library for AI-assisted work across any project. Dump links first; organize later.

- [Inbox](INBOX.md): add a bare URL whenever you find something useful.
- [Catalog](CATALOG.md): reviewed resources and their limits.
- [Categories](CATEGORIES.md): expandable subject areas.
- [Workflow](WORKFLOW.md): how to review, track status and consider adoption.

Ask an assistant: “Review my inbox, summarize useful resources and update the catalog.” Or: “Find resources relevant to this task; explain the fit before proposing an integration.”

This repository is a library, not an installer or mandatory stack. Nothing here automatically activates a skill, connects an MCP server, installs dependencies or grants access. Agents need access to this repository and must be directed to it; creating it does not configure every assistant.

The [FirstIQ-specific catalog](https://github.com/FirstIQ/FirstIQ.app/tree/main/docs/ai-resources) is maintained separately and may require access. This library remains useful without it. Duplication is intentional; there is no automatic synchronization. That link becomes available when FirstIQ's catalog PR is merged.

Private initially. Do not store credentials or secrets here. Upstream projects retain their own licenses; recheck terms before reuse.
